## Reporting a Vulnerability

The Fortress Command team takes system and application security with utmost seriousness. If you believe you have discovered a security vulnerability in Fortress Command, please report it responsibly according to the guidelines below:

### 1. Private Disclosure
- **Do not** report security vulnerabilities via public GitHub issues, discussions, or social media.
- Email your findings directly to our security maintainers at:
  **[alexhuhter313@gmail.com](mailto:alexhuhter313@gmail.com)**
- Use the subject line: `[SECURITY VULNERABILITY] Fortress Command - <Summary>`

### 2. What to Include
Please provide as much information as possible to help us triage and reproduce the issue rapidly:
- Detailed description of the vulnerability and attack vector.
- Step-by-step instructions or Proof of Concept (PoC) code.
- Impact assessment (e.g. unauthorized data read, privilege escalation, cross-site scripting).
- Operating system, browser version, and environment context.
- Suggested mitigations or remediations, if known.

### 3. Response Process
- **Acknowledgment**: You will receive an initial response acknowledging your report within **48 hours**.
- **Investigation & Verification**: Our engineering team will review the disclosure, verify reproducibility, and assess the threat model.
- **Remediation & Patching**: We strive to release a critical patch within **7 business days** of confirmation.
- **Public Disclosure**: A public advisory will be coordinated after affected users have had sufficient time to update their deployments.
